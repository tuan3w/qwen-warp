## K4 on-device MTP speculative decoding (src/mtp.cu, pack_mtp.py, spec.py) — 2026-10-31, RTX 3090 (lease held for every timed run, bf16 KV, greedy)
Design: one CUDA graph per cycle = verify (T=1+k rows [anchor, d1..dk], full BF16 lm_head + argmax for every row) -> accept kernel (device scalars: pos, cur ring slot, anchor, output ring, MTP positions)
-> MTP catch-up of the accepted rows (T=k+1 padded rows, int4 MTP layer, own bf16 KV, draft 1 from the last accepted row) -> drafts 2..k (single-row chains on the MTP's own post-norm hidden, restricted 64k int4 head).
Packed offline (`pack_mtp.py`): MTP layer + fc int4 g128 'int4clip' (E4's per-group MSE-optimal clip, scale rounded to bf16 first), draft head = lm_head rows of the 65536 draft-vocab ids (E4 corpus frequency top + 598 forced special/byte/template ids, `draft_vocab_64k.npy`) int4 g128; 209 MiB + 165 MiB.
